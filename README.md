# everafter-ai
AI-powered wedding planning web app that generates personalized wedding strategies, supplier recommendations, budget planning, compatibility analysis and curated venue suggestions for Romania.
The platform analyzes:
- wedding budget,
- city,
- wedding style,
- zodiac compatibility,
- menu preferences,
- entertainment,
- dessert preferences,
- and guest count

to generate:
- supplier recommendations,
- compatibility scores,
- budget planning,
- moodboards,
- and personalized wedding strategies.

Technologies used:
- HTML
- CSS
- JavaScript
- AI-inspired recommendation logic
