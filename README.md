everafter-ai
AI-Powered Wedding Planning Platform for Romania

EverAfter AI is an AI-inspired wedding planning web application designed to simplify and personalize the wedding organization process.

The platform combines:
- intelligent recommendation systems,
- AI-style compatibility analysis,
- budget optimization,
- curated supplier matching,
- and personalized event planning into a single interactive experience.

Project Overview

Planning a wedding is often a complex and stressful process that involves:
- budget management,
- supplier research,
- location analysis,
- event coordination,
- guest experience planning,
- and aesthetic consistency.

EverAfter AI was created as a prototype platform that uses AI-inspired logic and personalized analysis to help couples organize weddings more efficiently.

The application generates:
- personalized wedding concepts,
- supplier recommendations,
- compatibility scores,
- budget estimations,
- planning timelines,
- and customized event suggestions.

Main Features

1. AI Wedding Concept Generator
The system generates personalized wedding concepts based on:
- city,
- wedding style,
- guest count,
- budget,
- priorities,
- zodiac compatibility,
- and special wishes.

2. Curated Supplier Recommendation System

The platform recommends:
- venues,
- wedding planners,
- photographers,
- florists,
- entertainment suppliers,
- makeup artists,
- cake suppliers,
- accommodation options.

The recommendation logic analyzes:
- city compatibility,
- wedding style,
- guest capacity,
- estimated budget fit,
- and overall event compatibility.

The application supports all Romanian cities through dynamic supplier recommendation paths.

3. Compatibility Scoring System

Each supplier receives an AI-style compatibility score based on:
- wedding aesthetics,
- guest count,
- location,
- event scale,
- and estimated financial compatibility.

This creates a more personalized and intelligent recommendation experience.

4. Smart Budget Planner

The application dynamically generates:
- Excel-style wedding budget tables,
- category-based allocations,
- catering estimations,
- entertainment costs,
- dessert and cake costs,
- transport estimations,
- emergency reserve calculations.

The budget system adjusts automatically depending on:
- menu type,
- dietary preferences,
- alcohol package,
- entertainment type,
- candy bar preferences,
- and wedding cake selection.

5. Zodiac Compatibility Analysis

The application includes:
- zodiac personality analysis,
- romantic compatibility scoring,
- wedding atmosphere recommendations,
- personalized emotional experience suggestions.

This feature increases personalization and engagement.

6. AI Moodboard Generator

The system generates:
- aesthetic recommendations,
- wedding color palettes,
- visual atmosphere directions,
- luxury and style suggestions.

The moodboard adapts dynamically depending on the selected wedding concept.

7. Special Wishes Interpretation Engine

The platform analyzes custom user wishes such as:
- outdoor ceremony,
- champagne tower,
- mountain wedding,
- sea-view wedding,
- pet-friendly events,
- children-friendly weddings,
- intimate weddings,
- luxury weddings.

The application translates these wishes into planning actions and supplier recommendations.
